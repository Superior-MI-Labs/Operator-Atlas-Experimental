## v0.8 status

Qualified public research *workbench* with source-bound equation composition,
independent synthetic ablation, and active negative controls. Still not a
fluent language assistant, verified physical-model pipeline, or authenticated
public service. Unit typing and propagated uncertainty are additional gates.

# Public v1 release qualification — Operator Atlas

**This is a gate document, not a promise of capability.**

A local research app can be published as an educational demonstration today.
A claim of a usable neural-language assistant requires additional evidence.

1. Natural language: independent training/validation/test corpus; baseline
   perplexity and blind human quality assessment; no leaked training strings.
2. Learned mathematics: compare factorized, dense narrow, quantized and sparse
   variants with all state, metadata, gradients and runtime overhead accounted.
3. Real world knowledge: retrieval precision, unanswerable questions, false
   lexical matches, contradictory documents, and fact revision behavior.
4. Provenance: source hashes, document licenses, data owner control; import
   never silently performs model training.
5. Hardware: wall-clock p50/p95, peak RSS/VRAM, joules when measurable, CPU
   and GPU comparisons with realistic batch sizes.
6. Safety/privacy: authentication before remote binding, upload resource
   limits, consent for training, audit logs without copying private contents.
7. Diagnostics/reproducibility: clean extraction, `./launch.sh doctor`, seeded
   experiments, artifact hashes, known negative findings, and source-of-truth
   documentation derived from recorded experiment results.

**v0.7 meets only the local research-demonstration subset**, not the full
language, evaluation, hardware or public-server criteria.


## v0.9 review

A public **research-demonstrator v1** could legitimately present supported equation fitting and source-backed citation/retrieval, conditional on displaying its constraints. A general-purpose **intelligence-model v1** is not qualified: the character decoder is incoherent, retrieval is lexical, unit semantics are absent and performance has not exceeded byte-matched neural baselines. Release scopes must be named unambiguously.
