# Operator Atlas 1.0 — Continuation

This package evolves v0.9; it does not introduce parallel runtimes, second equation stores, or GUI-owned inference. The user can install it beside prior releases and run `./launch.sh doctor`, `./launch.sh study-real`, and `./launch.sh`.

New evidence: the 16-term scalar equation family loses to an AR2 forecast on predeclared chronological sunspot splits. Respect this negative result. Do not turn the experimental character model into a fake chatbot via canned answers. A future neural research track needs independent, licensed text, stronger tokenization, scale-matched baselines, measurable CPU/GPU latency and real held-out language metrics.

Priority if resumed: (1) unit-aware equation composition with propagated uncertainty, (2) separate genuine semantic question benchmark instead of hand-authored overlapping tokens, (3) architecture experiment selecting operators under real hardware cost/quality, (4) data-rights review and explicit license choice. Do not grow the GUI or invent an agent loop until these tests justify it.

Source of truth: `atlas/`, public raw reports in `results/`, versioned README and `docs/WHITEPAPER_V1.md`. Generated PNG/PDF are derivatives, not scientific evidence owners. Rebuild release via `python tools/package.py <output>` and validate extraction with `./launch.sh doctor`.
